# E-Commerce Customer Churn Prediction



\## Project Overview



Customer churn is a critical challenge for e-commerce businesses because retaining existing customers is often more cost-effective than acquiring new ones. This project uses Machine Learning to predict whether a customer is likely to churn based on demographic information, engagement behavior, shopping activity, and account-related metrics.



The project also includes a Streamlit application that allows users to enter customer information and receive real-time churn predictions.



\---



\## Business Problem



Customer attrition directly impacts revenue, customer lifetime value, and long-term business growth.



The objective of this project is to:



\* Identify customers likely to churn.

\* Predict churn probability using machine learning.

\* Enable proactive retention strategies.

\* Support data-driven business decisions.



\---



\## Dataset Description



The dataset contains customer information including:



\* Demographics

\* Membership details

\* Login activity

\* Shopping behavior

\* Cart abandonment metrics

\* Email engagement

\* Customer support interactions

\* Financial and loyalty attributes



Target Variable:



\* Churn (0 = Active Customer, 1 = Churned Customer)
